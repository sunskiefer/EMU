909MPC 0.2.0 (pre-release, offline build only). Roland TR-909 emulation for Akai Force / MPC OS. Not tested on a Force or any MPC yet. New in 0.2.0: builds for the new-generation 64-bit MPCs and for MPC OS 3.10.1. Three zips: `-mpc-armv7.zip` (Gen1 MPCs and the Force, MPC OS 3.x, install.sh), `-mpc-aarch64.zip` (new-generation 64-bit MPCs, install.sh) and `-mpc-sdk.zip` (one folder for every MPC on MPC OS 3.10.1: turn on External Plugin Support in Preferences, Enhancements, and copy the folder into `VST2 Plugins` on a drive). The sound and panel are the same as 0.1.0. Not tried on any device.

Port by L'Cronx of the emulation by lemus-dev (https://github.com/lemus-dev/lemus), AGPL-3.0. No ROMs are included: bring your own.

Needs: the TR-909 program ROM v4 (8192 bytes), the hi-hat, crash and ride ROMs (32768 bytes each) and the factory patterns ROM. Put it in the plugin's roms folder; it is found by SHA-1, so the file name does not matter. Without the program ROM the voices play from MIDI only (voice mode). Without a cymbal or hi-hat ROM, that sound is silent.

Install: unzip, copy to the device, run `sh install.sh` as root (stops MPC, backs up MPC.settings, registers the plugin, restarts MPC), then add the plugin to a track. `sh uninstall.sh` removes it. The how-to is in docs/README.md inside the plugin folder.

Known limits: the voices are a circuit solver. CPU use on the device is unmeasured and may be too heavy.
